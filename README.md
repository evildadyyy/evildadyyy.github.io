# АУВД Кутузовский

Учебный портал Академии УВД Кутузовского федерального округа. Здесь доступны видеолекции, тесты, библиотека и игровые правила.

Курсант заполняет профиль на сайте и открывает переписку кнопкой «Чат». Когда владелец назначает роль инструктора или главного инструктора, в том же браузере появляется «Вход». Кабинет показывает разделы, доступные по назначенной роли.
